# VoiceStudio model parameters and CPU coverage

The weight registry contains **73 entries** and **7 runtime-selected asset groups**. The desktop catalog has **46 selections** and the mobile contract lists **11 packs**. These sets overlap. For example, the same Zipformer checkpoint powers desktop and phone dictation. Git tracks the integration code, manifests and example audio. The model weights are downloaded separately.

The inventory covers the repository at [fcd54f2](https://github.com/Sarfia-786/adv-eleven-labs/commit/fcd54f246fd4b1588768b80acb6675325ab56c3a), including training defaults, evaluation helpers and provider presets. The desktop catalog, registries and mobile contract define what the app can select. An installed copy can have a different selection.

M means million and B means billion. Rounded figures describe the published architecture or named component. A precise **stored** figure counts tensor elements in the cited checkpoint and may include buffers, duplicate or folded tensors, or omit external components. An ONNX initializer count measures exported constants. Quantization changes how weights are stored. Counts for GGUF, int8, 4-bit and MLX variants use the parent architecture where identifiable. Adding these rows would count shared weights more than once.

## GitHub Actions CPU coverage

The audit branch runs the existing CI suite and four independent real-inference jobs. Each model is downloaded at an immutable revision, decoded or synthesized in an offline process, and removed from the runner before the next model. The transcript checks use the English dictation sample or the Mandarin preview. Kitten must return a finite, non-silent waveform. A failed model makes its job fail.

| Job | Real model coverage |
| --- | --- |
| Sherpa | All seven desktop dictation checkpoints, including two Parakeets, three Zipformers, streaming Paraformer and Whisper Tiny |
| Whisper small | CTranslate2 Tiny, Base, Small and Medium |
| Whisper large | CTranslate2 Large-v2, Large-v3, Large-v3 Turbo and Distil-Large-v3 |
| Kitten | Desktop Mini v0.8 synthesizes English speech on CPU |

These 16 integrations have weight-based checks. The other rows describe the sources and available runtimes. CUDA-only Ming and MOSS SoundEffect require an NVIDIA runner. The MLX adapters require Apple silicon. Large configurations such as MOSS-TTS-v1.5 plus its codec exceed a standard runner's memory at their published floating-point precision. Provider API calls require a separately configured service. GitHub's standard public-repository Linux machine offers 4 vCPUs, 16 GB RAM and 14 GB SSD.
